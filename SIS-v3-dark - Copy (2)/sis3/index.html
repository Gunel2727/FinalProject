Bilməli olduqlarınız

Sistemə necə daxil ola bilərəm?⌄

Hesabınız Admin tərəfindən yaradılır — açıq qeydiyyat forması yoxdur. Email və müvəqqəti şifrənizlə, yaxud institutun Google hesabı ilə "Daxil ol" səhifəsindən giriş edə bilərsiniz.

Admin, Müəllim və Tələbə rolları nə ilə fərqlənir?⌄

Hər rol öz iş axınına uyğun fərqli görünüş görür: Tələbə kurs/qiymət/davamiyyətini izləyir, Müəllim öz kurslarında qiymət və davamiyyət qeyd edir, Admin isə departament, proqram, semestr və istifadəçiləri idarə edir.

GPA necə hesablanır?⌄

GPA hər semestrdəki kurs qiymətləri və kreditlər əsasında avtomatik, real-vaxt rejimində hesablanır və tələbənin dashboard-unda dərhal görünür.

Yalnız öz kursumdakı insanlarla yaza bilərəm?⌄

Bəli — daxili söhbət yalnız eyni kursda olduğunuz müəllim və ya tələbələrlə yazışmağa icazə verir, bu da əlaqələri kurs kontekstində saxlayır.

Transkriptimi necə əldə edə bilərəm?⌄

Tələbələr "Qiymətlər" səhifəsindən bir kliklə rəsmi PDF transkriptini birbaşa endirə bilər.

Akademik idarəetməyə bu gün başlayın

Admin tərəfindən yaradılmış hesabınızla daxil olun və tələbə, müəllim və ya admin təcrübəsini kəşf edin.
